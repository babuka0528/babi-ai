BABY AI APK бүтээх заавар (утсаар)

1. GitHub дээр New repository дарж baby-ai нэртэй repository үүсгэ.
2. Repository дотор Add file > Upload files дар.
3. Энэ ZIP-ийг задлаад доторх БҮХ файл, хавтсыг сонгон upload хий. .github хавтас доторх workflow файлыг заавал оруул.
4. Commit changes дар.
5. Actions таб > Build BABY AI Android APK workflow > Run workflow.
6. Амжилттай дууссаны дараа тухайн run-ийн Artifacts хэсгээс BABY-AI-debug-APK тат.
7. Татсан ZIP-ийг задлаад app-debug.apk дээр дарж суулга.

Тайлбар: Debug APK нь туршилтын суулгац. Бодит AI хариулт ажиллуулахын тулд backend сервер болон AI provider API key-ийг тусад нь аюулгүй тохируулна. API key-г web эсвэл APK дотор бүү хий.
